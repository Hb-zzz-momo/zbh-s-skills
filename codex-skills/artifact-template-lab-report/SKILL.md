# 实验报告模板

每次报告自检执行[独立审查与评分循环](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/independent-report-review.md)：1号制作与修改，2号真实subagent独立审查评分点、实验运行、逐张截图完整及重点红框、原顺序、详细程度与美观，3号另一真实subagent独立评分并给建议；修改后再次交2号和3号，默认至少五轮或有完整依据的满分。最后交付版本须与最后独立审查/评分摘要一致，作者自检不能代替此流程。

## 先确定依据
本实验有专属skill时先全文读取并第一遵循；本通用模板skill第二遵循，只补充未规定事项，不能覆盖专属的步骤、代码、输出或版式要求。本次用户明确要求仍优先。

实验范围/评分以当前课程通知为准，版式以明确指定模板为准，事实以真实源文件与运行证据为准。先读取 `C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/courses/index.md`，只加载命中的课程。有本课模板不得使用 `assets/reference.docx` 替代；确实无本课模板且用户允许自行设计时才参考该资产，保留资产不变。

按 `C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/e2e-lab-workflow.md` §1.1 完整读取当前教程、要求、相关数据及模板；逐页检查PDF/PPT截图、标注、正反例和提交示例，核查影响实验的关联教程。按原编号拆子步骤，记录页码、类型/条件、实际操作、判据、证据位置/批次、报告位置与交付位置。冲突保留各自来源及采用解释，不能只依赖提取文本或概括性检查。

执行者、即时交接、排查无解后的询问和最终人工复做差异核对，遵守[执行交接与最终来源核对](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/e2e-lab-workflow.md#03-执行交接与最终来源核对)。仅对用户明确确认手动复现的对应范围，自然化正文、知识点问题及图注中的过时归属和制作话术；已有确认沿用，未确认部分保持真实，确认执行不等于独立撰写。按[报告叙述归属与措辞](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/report-evidence.md#8-报告叙述归属与措辞)第8.3节保留AI参与声明、位置清单与适用的独立标注预览，最终回复集中汇总。详细来源、交接和复做差异留存内部记录；独立agent复核归属、措辞与披露完整。

## 本课模板与讲义完整保留（硬要求）

有本课模板必须使用本课当前实验的模板副本，禁止套用其他课程模板、历史参考件或通用模板。只有确实没有本课模板且用户允许自行设计时，才考虑参考件，不能冒充本课模板。

所有课程实验只要有明确步骤，就保留全部原内容、完整代码、图片、理论及原顺序，不删减、合并、重排或只保留关键实现。除题目要求自行编写的代码外，默认不额外补代码、输出表达式、单元或功能；只有用户明确允许适当扩展时，才在完成原步骤后单独做授权范围内的延伸，不替换原要求。机器学习允许并尽可能补充仅展示已有数据或计算结果的代码，具体边界见课程规则；该例外不授权其他新增代码。“详细一点”不等于允许扩展。必须读取[完整执行与验收规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/template-lecture-fidelity.md)，逐项核对后才称全部完成。

机器学习执行[本课程规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/courses/machine-learning.md)：填原作业并尽可能在原格后添加仅展示已有数据或结果的独立代码格，其他代码不额外添加；教师代码及原参数逐格实际执行，有输出全部展示，无输出不占位，不新增AI注释，内容和格式全量自检；最终HTML必须经教师脚本或代码回读后在新Jupyter内核全量复验。授权扩展另列。其他Notebook同样遵守默认不补代码及明确扩展授权的边界。

Notebook及其导出报告同时遵守[逐格执行与原始输出规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/notebook-output-fidelity.md)：干净Jupyter内核从头逐格执行，保存未经后处理的快照，正文使用原生输出并比对哈希及原生导出；不手写、改写或拼装结果。无输出不放“已执行”“无显示输出”等占位说明。正文与代码注释清理制作/带练提示和对照提示，旧示例输出留在原件备份，完成版默认显示当前实测输出；此例外不删除实验要求、原代码、理论或步骤。发现与旧保留规则冲突时向用户说明采用依据。

## 母版保留

交付前按[执行输出与完成声明规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/verification-completion.md)检查完整输出、日志与诊断，分别判定正确性、必要视觉和最终包版本；未分类警告、必做未验证不能称全量完成。原生警告必须保留并判断影响，不能以零异常或Word生成成功代替验收。

复制模板替换内容，保留页面/页边距、表格宽度边框、固定栏目、字体、编号与教师栏。定稿删除填写指导和占位，保留教师明确要求保留的文字；栏目和提示的颜色按当前母版与用户选择继承，不把填写指导当作定稿内容。不强制跨课程七章或知识点栏目；课程固定的知识点栏目按原字段填写课程内容，AI披露按指定栏目或随附文件呈现。自动编号须读numPr并看渲染。长正文行高可自动增长，不拉伸图片；图与图注同一段并保持整段。

模板提示也是内容要求：要求写清搭建步骤时，在原栏目内写实际前提、具体操作、配置和验证；环境摘要或脚本路径不能替代关键方法。等效步骤与教程原操作分别标明，不把参考命令写成本人执行记录。

## 证据呈现按课程路由
Web课程按[全部教师踩分点与注释规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/courses/web-app.md)执行：功能与质量、注释、深度/问答、结果、结构、心得及提交条款逐条回填，源码与最终Word正文逐语言/模块统计有效注释，核心代码可复制，运行效果用真实截图；不能只给代码截图或总注释比例。其他课分别提取代码、SQL、配置、命令、结果的呈现要求。未指定时允许文字代码和可追溯日志，不做“一律截图”的通用假设。真实截图保留任务标识/关键输出，裁剪不隐藏失败；存档日志截图注明性质。截图前隐藏/移出Computer Use发光指针、控制浮层和鼠标指针，截后逐张放大检查，发现即重截，不得涂改遮盖。

## AI Report真实对话截图（每条必备）

每条AI Report都配一张真实GPT对话场景截图，同一张图清楚包含用户提问及已生成的部分回答；保留GPT界面、未经改动原图和完整问答文字。图号与条目一一对应，固定五字段及实际AI参与披露继续保留。不能用终端日志、手绘/HTML仿制界面、拼接问答或仅有提问的画面替代。

优先截取真实原始对话；需要补采时直接提出实际知识疑问，图注只说明知识点，后补来源、采集日期及模型未知等如实写入指定AI字段或披露附件，并在证据台账可追溯。旧图含制作话术须重新真实提问采集，保留旧原图与原问答，不改像素、不拼接、不裁掉关键内容；不冒充原始排错、原代码生成或实验运行证据。用户确认手动复现不免除截图与AI披露。按[截图采集与验收细则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/report-evidence.md#84-ai-report真实对话截图每条必备)逐条核对；未取得合格截图时标明缺口，不宣布所有AI Report已补齐。

## 验收

成稿后重新打开完整原教程，按原编号逐项反查代码、真实结果/日志、截图或有依据的例外、正文章节/页码和最终包；独立确认图中规则与判据，正文自检、两个校验器一致或零异常不能证明符合题目。

1. 从当前课程模板比对固定栏目与结构；不要把本技能历史参考件的七章硬套进Web报告。
2. 执行 `scripts/check_report.py --template <课程母版.docx> --report <报告.docx> --code-presentation text --result-presentation either`；参数按本次课程取值，Web运行截图另按覆盖表人工核查。检测器只识别部分文本特征，不代表功能评分。
3. 用Word导出或documents渲染PDF/PNG，逐页看字体、代码可读性、图表比例、孤立标题、越界、空页。跨模板时重新测量边界，不沿用assets/layout-bounds.json的其他课程值。
4. 模板固定的“知识点疑问/解答”等栏目按原字段写课程内容与实际验证，配真实验证截图和运行证据；AI披露按指定栏目或附件交付，工具对话截图不作为实验验证证据。仅在用户明确确认手动复现范围内自然化正文的AI归属/间接说明，未确认部分及课程要求的AI披露保持真实，减少“本人”与状态/流程元叙述。按[披露交付规则](C:/Users/zbh/.agents/skills/course/course-lab-workflow-zh/references/report-evidence.md#83-ai披露与位置清单每次报告交付必做)保留AI参与声明、含最终原文/位置的清单及适用的独立编号标注预览，最终回复集中汇总实际参与范围；独立agent复核归属、措辞和披露完整，结论记内部记录。
5. 每项必做要求对应正文、源码、真实证据；未核验项单列，不能宣布可提交/A+。教师成绩与评语始终留空。
6. 按教师提交示例核对目录层级、命名和报告/源码相对位置，打开或解包最终文件；检查需要交付的实现、校验/复现程序、依赖与参数说明，以及本次身份隔离要求涉及的图片、批注和元数据。

长代码按实际视觉行数安排分页；短函数保持完整，长段最后两行相邻，避免整段强行绑定造成半页空白。分页修改后重新导出并检查受影响页；仅当其余页图像摘要完全相同时才可复用原逐页记录。

通用检测器对有章节或图片的文档返回0时，检查其识别范围；自动编号需核对numPr，VML图片与红框需核对关系及真实PDF数量。记录检测器限制，不将“0异常”代替完整结构和图片验收。

教师数据含其他学生标识而提交有身份排除要求时，保留原数据、实际接口和原始响应，提交副本按统一规则匿名化全部同类标识，明确副本性质并分别记录原始与副本摘要、验证业务值未变。不得针对单个身份改源数据或把匿名副本当作原始执行证据。

源代码复制到报告后核对一致性；修改判据、源码或配置前保留旧版本与原始结果，重跑受影响作业并更新校验、最终状态截图、正文、图注和交付包，不将新结果倒填到旧运行。未受影响证据核验仍适用后保留并说明阶段；加载中页面不证明成功。过程与写作溯源按course-lab-workflow-zh记录在课程目录。

分别判定实验符合要求与实际执行、报告事实与渲染、交付包完整性。全部本次必做项和必要核验闭环才可称全量完成；可选未执行、条件未触发、必做阻塞/未核验和平台未提交分别列明。打包成功与检查器通过不能单独证明实验全部完成。

注释须核查最终Word正文，不能以源目录存在注释代替。按课程规定记录注释覆盖口径并逐模块看有效性，代码外分析不计为注释；代码格式化和复制后不得丢失注释；模板及讲义的原代码必须完整保留，节选只能作为额外说明。保留模板固定栏目，在其内部明确标出步骤、核心代码、运行结果与分析；逐项写清实际操作和验证结论。分页时把说明性代码注释与后续语句保持相邻，避免孤立在页尾。没有可复现评分依据时交付证据清单和风险，不凭主观精确自评分宣布A+。
