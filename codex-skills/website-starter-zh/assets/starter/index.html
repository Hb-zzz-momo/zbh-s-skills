从空目录开始：准备你的阅读角网页

  1. 新建文件夹，在记事本或编辑器复制下面完整代码。
  2. 另存为 index.html，保存类型选“所有文件”，编码选 UTF-8；确认不是 index.html.txt。
  3. 用浏览器打开。修改代码后先保存，再刷新页面。三课练习都在这一个文件中完成。

CSS 写在 head 内的 style 标签中；JavaScript 写在正文后、body 结束前的 script 标签中，不必新建其他文件。

<!doctype html>
<html lang="zh-CN">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>我的阅读角</title>
  <style>
    body { font-family: sans-serif; line-height: 1.8; padding: 24px; }
    .reading-note { border: 1px solid #16362e; padding: 16px; }
    .reading-note h2 { font-size: 16px; }
  </style>
</head>
<body>
  <section class="reading-note">
    <h2>周三，一起读十页</h2>
    <p>带一本喜欢的书，来图书馆二楼。</p>
  </section>
  <button id="ready">准备好了</button>
  <p id="message">等你准备</p>
  <script>
    const button = document.querySelector('#ready');
    const message = document.querySelector('#message');
    button.addEventListener('click', () => {
      message.textContent = '书已备好，周三见！';
    });
  </script>
</body>
</html>

三步检查：HTML课改标题和地点，保存刷新应看到文字变化；CSS课把上面已有规则的 padding: 16px 改成 padding: 24px；JS课修改已有回调的反馈文字，刷新再点击按钮。不要把同名代码重复添加两次。

没有变化时：检查扩展名与UTF-8；确认保存并刷新；CSS是否在 style 内、类名是否一致；JS选择器是否与唯一id一致，且脚本位于对应元素之后。

第 01 课HTML / 结构

先说清楚，内容是什么。

给“校园阅读角”写一条通知。标题和正文都能显示文字，但它们承担的角色不同。

想一想标题为什么不直接写成一段话？

HTML 用标签描述内容的角色。<h2> 表示章节标题，<p> 表示段落。结构清楚，同学更容易浏览，辅助阅读工具也能识别层次。

轮到你了 ↗

在自己的 HTML 文件中，把通知标题改为“周五，交换一本好书”，再把地点改为“教学楼一层”。保存后刷新，确认两处都变了。

核对：标题仍在 h2 中，地点仍在 p 中，开始和结束标签成对出现。

这一课的链路 通知文字 → HTML 标注角色 → 浏览器呈现层次 → 结构帮助读者理解内容。

第 02 课CSS / 样式

让重要的内容，先被看见。

阅读角的通知已经写好。接着给它留出呼吸的空间，让读者一眼找到标题。

想一想为什么改一个选择器，就能改变一类内容？

CSS 的选择器先找到元素，再用声明设置外观。这里的 .reading-note 找到带这个类名的通知；内边距让文字与边框保持距离。

第 03 课JavaScript / 交互

给一次点击，一个回应。

让阅读角多一个“准备好了”按钮。点下去，页面给出反馈，读者就知道自己的操作已生效。

想一想按钮怎么知道自己被点击了？

先找到按钮和提示文字，再用 addEventListener 监听点击。当事件发生，回调函数用 textContent 更新文字。

显示 6 条知识

HTML

标签为内容命名

h1 到 h6 描述标题层级，p 描述段落。先选合适的语义，再用 CSS 调整大小。

01
HTML

给输入框一个标签

label 的 for 对应输入框的 id，把说明和控件关联起来。点击标签也能聚焦输入框。

02
CSS

选择器决定规则用在哪里

.reading-note 匹配带该类名的元素。同一个类名可以复用，避免为每一条通知重复写样式。

03
CSS

盒模型帮你理解留白

内容向外依次是内边距 padding、边框 border 和外边距 margin。一个管框内距离，一个管框外距离。

04
JavaScript

事件把操作和反馈连接起来

addEventListener('click', ...) 在点击发生时执行函数。先监听，再由一次真实操作触发反馈。

05
JavaScript

用 textContent 更新纯文字

把文字赋给元素的 textContent，它会作为文本显示。适合提示消息，不会把输入文字当作 HTML 标签解析。
