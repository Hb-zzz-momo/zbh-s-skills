# 验收清单
在报告中填写“已测/失败/未测”，不能默认勾选。

1. 内容：与需求对应，无占位、虚构成绩、错误链接或未说明的示例数据。
2. 操作：每个可交互入口有结果；正常、错误、空结果、未填、重试均可解释。
3. 浏览器：打开真实页面，保存操作结果与截图；检查控制台、资源路径。
4. 响应式：至少320px窄屏与常规桌面，不截断关键信息；长文本可阅读。
5. 键盘：可以到达核心控件，焦点清晰；表单有label、动态结果可读。
6. 范围：原型与真实服务分清；无未授权的外部请求、上传、部署、公开发布。
7. 交付：说明环境、入口、运行命令、修改位置、已知限制；在新目录按说明复现。

学习小站具体场景：切课、关键词+主题、无结果清空、三题全对/全错/漏答/重置、勾选与刷新。勾选仅本页，不表示真实掌握；答题分数仅反映当次选择。
