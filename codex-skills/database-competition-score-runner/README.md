# database-competition-score-runner

An agent skill for running multi-track database competitions with evidence-first score tracking.

It emphasizes:

- official-rule coverage matrices;
- exact commits and reproducibility;
- fresh-state functional testing;
- controlled performance experiments;
- clear separation of local passes and formal receipts;
- safe parallelism for independent worktrees.

Copy `SKILL.md` into a Codex skills directory or install the parent skill package through
your normal Skill workflow.
