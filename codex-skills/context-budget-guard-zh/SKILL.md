# 保守上下文节省

目标是少读重复材料，同时保持原任务的执行与验证要求。领域主技能决定做什么，本技能仅决定怎样定位材料与复用已读背景。

## 启用边界

- 只在预计会重复读取同一批材料、长任务接班或组织独立评审时使用；小任务直接完成。地图维护成本高于本轮重复读取成本时旁路。
- 保持自动技能发现；不修改全局 AGENTS、模型历史、客户端配置、hooks 或其他技能。无常驻进程、网络调用、自动化计划、新依赖或模型下载。
- 用户新要求、规则/身份/环境变化、输入不完整、缓存疑似失效时，直接读取相关原件。缓存失败只停用优化，继续已授权任务；原任务缺必要证据时仍按领域规则阻断。
- 这是项目内可丢弃的定位层，沿用已有 docs/project-entry、证据目录和记忆入口。不得为了接入本技能重建项目记忆或复制整份历史。

## 地图与读取

1. 先读适用规则和已有结构入口。首次仅用有限的目录列表/定向搜索确认任务相关范围，再按 [地图模板](assets/maps.md) 维护 `code-map.md`、`evidence-index.md`。已有等价索引就补字段并引用，避免平行目录。无代码任务将代码项标记“不适用”。
2. 地图只列职责、真实签名、主要数据流、测试入口、最近变更及来源定位；证据编号映射到原路径、证明内容、报告位置、验证状态和版本。未知写“未验证”，哈希不证明内容正确。
3. 常态先读地图相关段，再按路径、符号、页码或证据编号读原件；变化时检查依赖、调用方和验收影响。不能因“只读变化部分”漏掉影响范围。超过两次整读后优先采用定向读取；为排错或验收确有需要时允许整读。
4. 新文件、重命名、删除或规则范围变化时更新清单。清单之外不会被哈希检测；项目变更用当前任务已有的 Git 差异/文件清单交叉核对，不另加全仓库轮询。

## 状态观察（需要重复检查时才接入）

接入与命令、清单字段、边界示例见 [状态与场景](references/operation.md)。助手先用模板建立有限文件清单；脚本不会自动发现文件或推断完成状态。

- `check` 只读。使用文件完整内容 SHA256，不能单凭 mtime/大小认定不变；比较范围绑定项目根、任务/身份 scope 和清单。
- `record` 只在实际分析、必要验证和地图更新后主动执行，写入新观察基线；不在检测变化后立即自动推进基线。`observed_at` 是文件观察时间，`last_verified_at` 只能来自实际领域核验，不能自动改成当前时间。
- 仅当本轮是**已经授权的纯观察检查**、没有新任务/到期动作/必做验证、覆盖充分、无未决问题或外部依赖，并且脚本返回 `UNCHANGED` 时，输出一行“无变化”后结束这次观察。
- `CHANGED`：读取变化项和必要影响范围；`REVIEW_REQUIRED`：过期、待办或外部状态需核验；`UNKNOWN`：缺失、损坏、锁、超限或不支持的路径，回到正常定向读取。任何非零退出码均不得当作无变化。
- 只有经原证据确认会影响目标、结论、期限或需要用户动作的重大变化才通知。普通增量在任务内处理；不因接入本技能创建定时任务。
- 正在运行的实验、追加日志、进程状态、平台提交/教师批改/云同步、网络事实和环境健康不由静态文件哈希证明。必须通过原工作流的实际状态来源检查。

脚本只用 Python 标准库，`record` 仅支持本机 Windows；单次最多 64 文件、每文件 8 MiB、合计 32 MiB；2 秒为协作式读取预算（不能中断操作系统阻塞 I/O），控制文件各限 128 KiB。超限不自动扩预算、不拆批绕限；大模型、数据集、长日志由领域流程核验并登记真实结果来源，缺覆盖时禁止短路。

## 按需记忆与保守压缩

- 每任务先检索 3–8 条相关记忆作为软目标，不为凑数加载、不因上限省略关键约束。每条保留来源文件/位置、适用项目与身份、确认状态；可变化事实需当前核验。只加载相关历史，完整历史仍在原文件。
- 长期候选限稳定规则、常用路径、已确认事实、用户偏好、未解决风险。收工时若有新增才在现有任务记录中追加短候选，保留原话与助手归纳的区别、来源和待核验项；无新增则不写。
- “后台整理”在本版本中表示主任务完成后的可选收尾整理，不启动后台服务/额外 AI 任务。不得自动改写全局 memories、覆盖旧记录或把临时结果升格为长期事实；正式持久化须遵从目标记忆库规则及用户直接授权。
- 默认采用抽取式摘要或导航，原件不变。会议记录、旧对话、长背景和非关键网页只有在收益明确时才生成带原文指针的派生摘要。
- 禁止对实验数字和结果表、代码/命令、引文/来源、模板要求、验收条件、身份/路径做有损压缩。混合文本先划保护块；无法可靠分离时整段保留。摘要不得作为唯一证据。
- 本版本不安装或调用 LLMLingua、Mem0、LangMem、Graphiti；用户今后明确要求试点时另行限定输入和质量核验，不把本次设计当作安装授权。

## 独立评审材料

遵守领域规定的真实代理人数与独立评价要求；本技能不减少评审人数、不更换模型。每位评审只收到目标、完整验收条件、冻结版本/哈希、相关地图和原证据入口，以及其职责所需原始材料。保护内容逐字保留；评审可自行读取更多原件。初评不附作者预期结论、其他评审意见或未经证据支撑的“已通过”。原始意见、修订和复验照常保留。

## 完成与回退

地图对应当前版本、必要验证全部照常完成，才能交付。简述本次复用范围与未覆盖项，不承诺节省比例或“完全不影响性能”。需要停用时直接不调用本技能/脚本，原项目流程仍可运行；缓存可保留，无需删除或更改任何全局配置。
