# 最终自检：检查真实交付，不只检查格式

每次批阅、规则修改、技能更新在最终回复前完成相关检查。先修复可修复问题，再仅重验受影响项；不要求固定多轮，不为凑PASS修改记录。自检以原件、冻结规则、结果和实际测试为依据，不能只重复自己的结论。没有调用独立评阅者就写“自审”，不要写“独立审计”。

## A. 每次批阅结果

1. **输入和范围**：实验编号、选定提交、报告/规则/证据哈希及任务ID一致；16个实验分别100分，不跨实验串用题目。姓名/封面冲突不猜测；模板旧成绩不作依据。
2. **完整取证**：Word段落/表格/图片引用和页面位置能对应；核对原图与页面，查未知对象、漏图、裁切隐藏内容与未映射段落。识别问题如实标记，不把“图片数量相同”当成无遗漏证明。
3. **归属和事实**：题目、示例、预填解释不是学生答案；student_answer只是候选标签。模型观察中的命令/数值应能在引用原文或原图看到；普通命令输出不是学生解释。页面与原图矛盾须排除或待复核。
4. **逐项锚点**：全数覆盖该实验评分项，每项引用存在且可读；满分逐条件核对，部分分理由确实符合该项部分锚点，不能只因“差一点”套一半。核心错误、小缺漏、未完成、看不清分别处理。结果足以证明目标时，不额外追加单条命令截图要求；考查特定命令时不能从文件存在推断执行。
5. **宽容与公平**：逐项查有无重复扣分、非题面格式/字数/美观扣分、等价实现被误判、短心得被轻视。当前版本未有minor档时，发现锚点空白应提出统一修订或复核，不私设85%分数。也不能把题面当答案给分来抬均值。
6. **算分与状态**：核对行分之和和满分100；严格未决项保留上下界，不能取中点。具体建议另按合法档位计算，推定标明，暂按未体现采分点的建议不能写成确认缺答。失败不等于0。建议final_score=null，教师分/正式分只来自实际记录，展示和导出使用同一任务/版本，不能挑历史最高分。
7. **异常和交付**：保留API失败、重试和程序拦截的原记录；没有必要的新证据或修复不反复付费重跑。详细交付包括流程、逐项表、证据位置、原因、未决项及实际限制，术语用普通中文解释。不能把两份试批或自检通过说成全班评分公平性已验证。

不存在的引用、错误绑定或错版本必须修正后才可形成结果。严格模型不把题面当作答，事实冲突保留未决；具体推定建议另行标注疑点及可能影响，教师明确接受前不能记成已核实成绩。

## B. 校准与分布（请求涉及整班或规则变更时）

按同一实验、同一规则版本及选定提交统计；列具体建议人数、推定样本数和失败/未计分排除数。查看均值、中位数、标准差及直方图，85仅作参考；样本不足不宣称正态。区间不取中点，不能排除低分美化分布。自动权重建议仍排除未决/推定样本，至少20份。修改规则同批一致、保留旧版本，用教师标注及留出样本核对，不直接把样本调成85。工作台有统计诊断与统一权重预览，不能与已保存成绩混用。

## C. skill或程序更新

- 从源文件维护：入口模板、参考文档和唯一评分JSON；不要只改已安装副本。查明新增要求放在哪里，标清用户要求、方案参数、实现状态和验证范围。
- 先检查规则冲突：尤其旧50%档与拟议85%档、先评分后复核与先事实后评分、拟议HTTP接口与实际CLI。历史样本分数必须标明版本，不当成验收目标。
- 构建后执行`python scripts/audit_skill.py --root <skill目录>`。它只检查入口/本地参考链接、manifest完整性、16份规则和固定命令可用性，不调用外网、不验证语义评分、不运行学生代码。JSON结果中的限制必须保留。
- 执行skill-creator的quick_validate（该工具可用时）；运行与改动相关的项目验证。通用结构审计BLOCK按真实结果记录，只有明确声明且逐项核对的分发副本例外可解释，不能改写成工具PASS。
- 安装前核对旧manifest拥有的文件是否有本地修改，复制本次拥有文件并逐个验哈希；若有实际改动先合并，不盲目覆盖。检查安装副本、ZIP、源内容一致，不夹带学生报告、运行数据库或密钥。生成结果保存在skill之外，避免污染manifest。

## D. 必做的语义场景自审

这些是手工检查场景，不是用固定句子匹配代替评阅，也不是已运行的模型基准。若自动或人工前向演练，记录输入、实际输出和判断依据；没有运行就标未运行。

| 场景 | 应当出现的处理 |
|---|---|
| 题面写who --help，实际原图为LESS帮助 | 不把题目命令当实际执行；按对应项证据判定 |
| 模板讲解权限，学生只有ls -l输出 | 不把模板当自己的解释；可以认可输出已证明的目标 |
| 正确操作结果＋学生解释，未截每条命令 | 先看学习目标，不能无条件降半分；新minor档实施前不伪造档位 |
| hello.i存在，未见gcc -E命令 | 只确认阶段产物；特定命令事实未知，不编造，依当前规则复核 |
| 只有next和continue，未见step | 不当作两种单步都已演示；等价实现需解释证据 |
| 心得写“无”；另一份图片解析失败 | 前者是实际作答missing=false；后者待复核，不能混同缺答 |
| 同份报告换到高分班；要求“把全班拉到85” | 固定规则下该报告不因同学改变而变分；分布诊断不强制排名映射 |
| 要按85%档评分，但程序只有full/partial/zero/unresolved | 如实说明实现差距，按任务范围升级或给方案；不把旧程序结果说成新尺度 |
| JSON截断、缺项、绑定错或引用不存在 | 拒绝该响应/任务，不转0、不补造引用 |
| 只改skill，却想宣称已重评全班 | 只声明实际更新与已跑检查，不新增批量调用或成绩发布 |

## E. 自检记录最小格式

记录：任务范围与版本；检查项 → PASS/FAIL/未运行/不适用 → 实际证据；发现的问题及修复；重验结果；仍未解决的限制。最终回复简要说明改了什么、检查了什么、有什么尚未实现。不要只写“已全面自检无误”。

## 网页正式接通的附加门禁

- 验证原件上传后SHA-256与源文件一致，下载同字节；非法文件、过长路径和跨组学号冲突有明确错误。
- 名单和成员关系持久化，86名预置数据不打包到前端。保存失败不得显示成功。
- 双击任务、旧修订复核、跨版本发布不能重复调用或串卷；服务重启保留任务，运行中断需显式恢复，网络失败不自动重复付费请求。
- 使用真实Word报告覆盖分组深目录，特别核查Windows文件名长度；只过短临时路径单元测试不够。
- 页面展示真实作答/题目/示例标签、原始截图、页面图和逐项理由；缺证据不自动填0，待复核区间不混入均值。
- 对合成隔离报告测试复核及发布；真实学生仅试批建议，不伪造教师确认。校准规则有66个明确minor条件，其余项不得自动升档。
- 备份后校验全部文件指纹和SQLite完整性，恢复至新目录，重启后名单/原件/任务能读取；不能仅验证ZIP能打开。
- 验证正式服务入口、浏览器交互、导出、敏感数据不进入静态包；记录未解决项与真实教师校准边界。

汇总分组自检：两班成员去重、原班级新增学生自动反映、单班与汇总原件去重、归属不明禁止猜测、人工绑定后归原班、成绩导出包含两个班且保留原班级；个人应交数不得因汇总入口翻倍。异常Word自检：无效文件用中文解释且不生成提交/分数；合法文件仍能独立导入。

## Word图片角色与失败恢复

- 同段落“题目+学生截图”分别标记；题目文字不能得分，图片可作为候选学生证据。
- 检查题目要求后的裸命令截图、空段落图片、模板示例图和提供的代码；示例与未知证据不得升级为学生事实。
- 检查最终证据目录中的图片角色，而不只检查中间段落分类。
- 修复后以新任务重新提取，旧任务、原图、原始响应及绑定记录保持可追溯；不修改冻结证据。
- 只有完整grade响应才可本地重新校验；没有评分响应时提示重新提取并批阅。失败不记零分，新建议不替代教师确认。

响应完整性自检：模拟HTTP 200但finish_reason=length，确认事实阶段即停止、不进入评分、不自动重试、不产生分数；保留返回记录及输出用量。完整输入回显也不能通过事实结构校验。旧版英文错误在详情中应有中文原因，截断响应不能提供本地重新校验为成功的入口。真实新任务须验证两阶段完整返回、全评分项覆盖和未发布状态。

核对结果唯一性：材料末尾提供评分项完整ID清单和应返回数量；即使全部项目已出现，多出同ID记录仍须拒绝，不能自行合并存在差异的事实。错误提示分别列出重复、缺失、额外项，重试保留调用历史。

## 图文比例、自动复查与分布调参

- 验证16实验调权后各100分、项目保留、各档有效；默认按分值选约50分双证据，固定清单不随学生改变。identity独立。
- either能接受充分的学生文字；both满分需原始图与文字。题面/示例/页面上下文不冒充学生作答。已有文字不达标不归为整项缺答。
- 页面包覆盖互斥且完整；每包每目标有事实记录；漏包、篡改指纹、跨包引用、不可读或不确定都不能证明缺答。审核记录不能跨报告绑定。
- 追加复查至多一次；成功保留组合来源与旧原始响应，失败保留首次结果，不再重复付费。教师批量操作需要已核对勾选、逐项理由与修订检查。
- 调参预览不得写分数；保存政策只影响新任务。旧任务/人工确认/正式成绩不能被静默改写。参数变更引起证据判定变化需真实重批，不能用权重试算冒充。
- 目标均值/标准差只作参考与统一权重建议；样本少于20不自动拟合；未决区间不取中点。全满分样本不得被改成85分分布。
- 真实报告验收检查未决项变化、两阶段与追加调用、原件指纹、旧任务保留、页面交互和未发布状态。

- 命令带学生作用解释与题面命令须分别识别；空解释及纯命令不自动视为作答。错误命令来源只能隔离为本项复核，不能成为已验证事实；确认原模型响应留存，其他项目继续批阅。提取版本更新后使用新任务，不修改旧证据绑定。

## 文件优先导入与具体建议自检

- 严格结果中的硬异常必须检查recommendation/列表/教师接受全链：非法minor、不可读原图、格式异常事实不能经建议层恢复满分/部分分/零分或变成已完成；保留None、required_review_items及必审组，普通阈值调到100也不得隐藏。教师未明确逐项合法处理前不可保存复核分；普通软疑点的原推定行为仍须回归。
- 可读性沿事实证据链检查：即使grade只引用可读图注/页面，若observed_commands的实际来源仍是不可读原图，也必须硬隔离，不能通过改写grade引用列表恢复已核实命令或满分。保留原始事实响应与来源，历史图片接口与界面不得将裁剪外隐藏像素冒充学生可见作答。

- 重新批阅必须在列表每行、勾选批量栏和批阅/任务详情可见。隔离验证单份/批量、首次建job前失败、提取失败、已有建议/复核、运行保护、已发布保护、新旧修订；新任务不覆盖历史、不调用发布。历史发布保护须覆盖所有任务动作及执行前复查，旧版已经入队的retry也不能绕过。历史结果和证据可只读打开，跨报告job/证据必须拒绝，查看不切换当前任务。
- 模拟POST已接收后响应断线、刷新后重试、任务已结束后重试：凭证必须在发送前持久保存，始终重放同一request_id和请求体；再次确认遭会话失败或401/403时仍保留旧凭证，只有成功核对才能清除。未知提交不能显示为未执行。明确拒绝、部分失败与界面刷新失败分别反馈；双击、初次批阅/重批/删除共享互斥保护。
- 模拟事实漏contradictions和未知引用，只隔离受影响项为未核实，不补造无矛盾或猜编号；绑定损坏/整体漏项继续拒绝。模拟非法minor和不可读裁剪原图，对应项目无所得分、missing=false，其他项目保留；原响应和原引用可追溯。完整grade才允许离线校验，不因fact响应存在就开放。
- 内存异常须保留类型和可读提示，不写空错误、不判学生缺答。图像包在整体读取前检查既有大小上限，页图/裁片及时关闭；Word转换与导入检查串行，不把None传作文件名，失败留诊断且只清理本转换拥有的Word进程。原件成功复现转换时，不声称已证实原件损坏。
- 补充名单只有教师确认后新增；学号复用、异名冲突拒绝。汇总只增加同届普通来源，拒绝删除原来源/改组类型/跨届/嵌套，名单及成绩派生去重。无效文件只建学生档案，不登记虚假报告和分数。
- 本轮按独立多agent评价规则冻结代码/证据：执行者与评审为真实不同身份，保存原始意见、修订及复验；未解决阻断不得自评覆盖。离线模拟、真实样本恢复及教师正式成绩明确区分。

- 列表删除验收必须在“报告与批阅”实际列表完成：不选中时每行看到删除；选中后直接看到批量删除；已有建议分、待复核和已复核但未发布的报告也可删除。不能以导入弹窗或详情中的删除替代列表验收。保护项显示禁用原因。用隔离数据覆盖单删、批删、部分失败继续、同一学生多版本修订变化、已评分报告删除和恢复；原件及评分指纹保持，真实学生不作为删除试验。

- 在隔离数据库和实际浏览器验证失败项删除/批量删除/撤销，成功识别项不重传；删除名单外文件后数量及确认按钮正确更新，电脑源文件指纹不变。
- 新增学生先展示候选学号/姓名/原班级，显式确认后唯一身份与成员关系写入，汇总同步、同学号异名拒绝；报告对应学生，原字节和实验归属保留，不调用模型。
- 用两种相反上传顺序验证唯一明确“新”标记成为最终报告；多份新、无新、姓名含新、正文新建指令、-1/(2)后缀、相同内容不同名称、教师明确选版及已发布版本都分别检查。旧原件和成绩保留，教学数据库与评分引擎选择一致，自动选版不评分/发布。
- 验证已登记失败/未匹配报告删除后不进入待办、个人作业统计或导出，可从已删除列表恢复；原件/失败调用/审计留存。排队、运行、旧修订、已发布保护不得绕过；重导同一已删除原件复用原记录。

- 首屏不要求班级/实验；文件名、Word封面及名单自动识别，混合班级与实验分别确认；当前筛选不能冒充识别结果。覆盖中文实验编号、仅封面有信息、未知/重名/学号姓名冲突、多班归属和实验冲突。
- 识别不产生作业或分数；确认保留字节及文件名，校验指纹/班级成员，凭证重试去重；错误实验修正需依据，失败不留假作业，成功文件不重复导入。
- 在实际浏览器分别验证单文件、多文件、文件夹及嵌套子目录：multipart只发送原文件名，中文、加号、空格、重复版本后缀正常；不把目录路径误报为文件名无效。制造一次识别失败后仅重试失败项，已识别结果/人工更正保留；格式无效文件应提示替换，后台路径校验仍有效。
- recommendation与严格result分开；原绑定、模型响应、区间、历史复核及正式分不变；建议总分等于冻结档位逐项相加，禁止中点凑85。
- 小疑点折叠且可以全部展开，默认重点至多3组；阈值调整只影响显示。身份、提取和版本阻塞始终显示，不能靠接受推定跳过。
- 只有教师勾选并保存才能接受推定，accepted_estimate_items逐项留痕；任意改档/改证据仍按普通复核校验，不能提交自由总分。推定零分missing=false，不伪造完整搜索。
- 用隔离虚构数据验证接受/拒绝、旧修订和不自动发布；用实际报告只读检查建议分及重点数量，不冒充教师接受真实学生成绩。实机页面、已保存结果指纹、skill分发哈希分别验证。
