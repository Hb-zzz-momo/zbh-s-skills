# Word结构优先批阅（后端0.3.0）

实际顺序：**Word原始结构 → 题目/示例/作答分类 → 原始截图 → 评分项证据配对 → 页面交叉核对与事实记录 → 评分**。

## 本地准备

Word只读打开原文件，旧doc另存生成的structure.docx；原文件哈希保持不变。docx直接读取原始OOXML，旧doc的图片来源准确表述为“Word转换后的OOXML媒体”，不保证与二进制doc内部压缩字节一致。

从结构副本提取段落、表格单元、文本框、图片关系及浮动锚点。media目录保存原始媒体字节和哈希；Word段落页码通过页面起始字符位置计算，并按文档顺序配对，避免空段落和合并单元格重复导致错页。PDF/整页图片用于核对正文和图片位置，不是Word内容提取的唯一来源。

题目/示例/作答分类是结构启发式：利用“实验步骤与结果”“心得”边界、明确任务提示和已识别教学背景。学生作答标签只是候选位置，不证明原创或正确。**不把与标准答案相同的答案当模板删除。** 实验2已将预填权限理论与学生解释区分；其他实验使用通用结构规则，不能声称16份都已完成真实样本验证。

每个评分项都有候选证据ID，按标题、邻近段落和关键词检索。候选用于导航，完整目录仍可查看，不能据候选未命中直接判缺答。

## 模型调用与计分

每份Word报告通常两次模型调用：

1. evidence_check：看Word作答原文、原始图及页面图，逐项记录实际命令、学生解释、具体观察和矛盾，不输出分数或档位。
2. grade：按原有评分标准、上述事实与原始证据给出逐项档位，程序按固定分值相加。

两个阶段均保留请求指纹、响应与耗时。核对阶段失败则停止，不跳过直接评分。事实记录也来自模型，不是独立教师真值；程序检查格式、绑定、证据来源，并对已明确的命令/解释条件做冲突拦截，不能保证消除所有语义错误。

新增拦截：仅引用题面/示例/页面上下文不能得分；执行满分需学生原始执行证据。实验2权限解释项需要观察到学生解释；实验3四阶段命令项需要观察到相应命令；next/step满分需要两种对应命令证据。命令别名/等价工具未能识别时转待复核，不直接判错或零分。这些拦截表达既有评分条件，不改变分值。人工可查原件后按同一锚点裁决。

学生明确填写“无”，按实际作答内容评判，missing=false；无法找到答案时才适用完整检索要求。原图与页面矛盾、结构提取不全、未知图片对象、页码无法对应等必须保留待复核原因。

## 产物与使用

现有import / prepare / run / batch命令保持不变；新准备的Word任务默认采用新流程。旧Word任务必须新prepare后才能再次发送，原历史结果保留。示例：

```powershell
python scripts/run_backend.py prepare SUBMISSION_ID --credentials "密钥文件路径"
python scripts/run_backend.py run JOB_ID
```

任务目录中可查：

| 文件 | 用途 |
|---|---|
| extractions/.../structure.docx | 只读原件的结构副本 |
| paragraph-pages.json | Word段落与页面位置 |
| word-structure.json | 段落、表格、图片关系及原图哈希 |
| classified-blocks.json | 分类标签、依据及邻近题目 |
| media/ | 原始图片，非整页裁片 |
| evidence-plan.json | 每评分项候选证据及页面覆盖核对 |
| checked-facts-*.json | 独立事实核对记录 |
| results/.../model-judgments.json | 最后评分阶段原始判断 |
| results/.../suggestion.json | 程序校验后的建议或待复核区间 |

原图和页面图片中的身份文字仍未保证全部遮盖；这里只对文字层做有限遮盖。裁切、旋转等尚未可靠还原的原图不发送隐藏内容，保留页面供人工核对。PDF仍能使用旧兼容路径，不能提取出不存在的Word结构。没有修改原评分权重、没有前端、没有自动发布学生正式成绩。
