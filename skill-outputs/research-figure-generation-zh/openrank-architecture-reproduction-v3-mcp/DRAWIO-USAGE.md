# Draw.io Usage

## Use This File For Clean Presentation

```text
openrank_architecture_reproduction.fixed-background.drawio
```

This file embeds the validated high-fidelity SVG as a single image inside draw.io. It should open without layout collapse, text reflow, or broken auto-routed arrows.

## Do Not Use For Visual Presentation

```text
openrank_architecture_reproduction.drawio
```

This earlier file is a native draw.io structural draft. It uses simplified blocks and auto-routed connectors, so draw.io can reflow labels and routes after opening. It is not suitable as the visual reproduction.

## Editing Boundary

The fixed-background file is visually stable, but the whole figure is one embedded SVG image. You can move, scale, crop, annotate, and place extra draw.io labels/arrows on top of it. You cannot directly double-click every original label or icon as independent draw.io objects.

For detailed element editing, use the SVG in Inkscape or revise the generation script, then regenerate the fixed-background draw.io file.
