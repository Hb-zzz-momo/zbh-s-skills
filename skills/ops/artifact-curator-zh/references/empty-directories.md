# 普通空目录清理

目标：整理完成后，用户看到的普通分类确实有内容。空壳用清单留记录，不必留下整棵空文件夹。此能力只移除目录，不删除文件；原有文件清理器的限制保持有效。

## 先确认范围

完整列出本次项目的目录与文件，包含隐藏项和零字节文件，检查现行导航及脚本引用。保护工程原生结构、运行时约定、真正的独立恢复备份；任意命名的保护位置必须显式传入 `--protect`。脚本还会保护 `.git/.hg/.svn/backup/backups/独立备份/恢复备份`。不能把备份子目录另设项目根绕过保护。

看见目录里没有东西，不代表已证实为空：读取失败、链接、重解析点、离线或召回属性均记未知并保留，未知项的祖先也不会成为空目录候选。扫描使用新鲜属性读取，避免使用目录枚举缓存。Windows 长路径仅在内部读取时转为扩展形式，不允许输入设备路径、越界路径或短路径别名。

成功信号：每项候选的完整子树已枚举，里面只有同批候选空目录；没有任何文件。保护区和未知区分别列出，不能把未扫描工程说成已清零。

## 从扫描到执行

使用实际安装的本技能路径代替 `<skill>`。输出放已有的项目核对记录或 D 盘临时目录；不要创建一套空的报告目录模板。下列路径仅为参数示意，不可直接复制当成真实计划。

```text
python <skill>/scripts/empty_directories.py scan --root <项目绝对路径> --protect <工程相对路径> --out <已有记录目录>/empty-plan.json
python <skill>/scripts/empty_directories.py check --plan <已有记录目录>/empty-plan.json
python <skill>/scripts/empty_directories.py apply --plan <已有记录目录>/empty-plan.json --plan-sha256 <check输出的sha256> --journal <已有记录目录>/empty-cleanup.jsonl --workers-stopped
```

`scan` 只读取项目并独占新建计划，`check` 完全只读；`--protect` 可重复，表示整棵保护子树。计划里的 `items` 是从最深层开始的精确候选，`unknown` 是未证实状态，`skipped` 是跳过的保护区。扫描结果不是删除授权：执行者先核依赖/引用，在用户已授权范围审定；批量删除按独立评价要求复核计划。计划在评审后冻结，不边评边改。

`apply` 才操作目录。`--plan-sha256` 锁定已审计划字节，`--workers-stopped` 表示执行者已停写并关闭本轮预览/消费者，脚本不自动检测进程或取得用户授权。全批预检根、候选、祖先的身份和当前子项，任一异常先拒绝整批。每项删除前再检查身份、确实为空，先刷盘写意图，再调用一次非递归 `os.rmdir`，成功后记结果。零字节、隐藏文件或新到文件都会阻止删除。日志用独占创建，拒绝覆盖已有日志。

日志首行的 `plan_file_sha256` 是 CLI 使用的计划原文件摘要，须与冻结值一致；`plan_content_sha256` 是规范化 JSON 内容摘要，两者含义不同。直接调用 Python 函数时未传原文件摘要则前者为 null，不冒充文件已绑定。

限制：逐项操作不保证整批原子性，Windows 路径检查也不保证抵御恶意并发祖先置换。必须停止写入；出现锁定、权限或竞态失败就停止，保留 `partial` 和真实已删项，不杀用户进程、不递归兜底、不盲目重试。先核失败现场，再为余项重新扫描和审定。

## 清后核对与恢复

重新扫描相同普通范围，确认可清空目录为零，核文件路径集合与内容指纹不变；导航/规则文件如需改写，另存原字节与差异，不能混进“所有文件未改”的声明。记录保护区、未知项、实际删目录数、当地观测时间；删除空目录不代表释放了多少磁盘或内存。

确需恢复旧路径时，依据日志中 `removed` 从浅到深逐个建目录；日志最后一项只有 `intent` 时，先现场核实是否已移除。恢复前仍检查根、祖先、冲突和链接，不覆盖任何现存文件。可在隔离测试中演练；恢复只能重建空路径，不还原目录身份、权限或原时间，也不能恢复本就不存在的文件。本功能不提供自动恢复命令，不能把手工建目录说成完整备份恢复。无需恢复时只保留一份计划与日志，避免实体空壳重新出现。

云盘本地删除可能同步到云端；脚本不调用云端 API。只报告本次本地验证，云同步、WPS 打开和云端恢复分别核验。客户端重建空壳时记录事实，不循环删除。

## 实现依据

- [Python `os.rmdir`](https://docs.python.org/3/library/os.html#os.rmdir)：只移除空目录，非空会报错；所以不调用递归删除。
- [Microsoft 文件属性](https://learn.microsoft.com/windows/win32/fileio/file-attribute-constants)：重解析、离线、召回属性表示需要另行处理的状态；因此无法可靠枚举的云端目录列未知。
