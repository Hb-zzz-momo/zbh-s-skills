## 当前 server111 的最短下一步

本地 PowerShell：

```powershell
ssh -G server111 | Select-String '^(hostname|user|port|identityfile) '
ssh -vv -o ClearAllForwardings=yes server111
```

第一条核对实际生效目标和账户；第二条区分认证、网络、会话问题。若其他连接可用，从该连接执行 whoami 确认用户名。收集最后约15行相关日志，并保留 Authenticated to 等阶段性证据；不提交密码或私钥。

## 执行工具的独立限制

当次电脑控制运行时多次提示 app-server 程序缺失；助手侧读取私钥与出站 SSH 也受到权限限制。这些是助手环境的执行失败，不能作为用户密码错误或服务器禁止登录的证据。

没有成功执行记录的修改只能称为“已给出教程”。第一台代理通过是用户提供的测试结果；第二台登录尚未验证通过。

## 本次形成的工作原则

- 先验证账号登录，再配置免密；先验证隧道，再设置环境变量；最后验证目标应用。
- 普通 SSH 与专用代理隧道使用不同别名，减少多条连接重复绑定远程10801。
- 区分本地设置、远程设置、Shell 环境和进程继承，避免把“全局”理解成所有应用自动生效。
- 记录成功信号及覆盖范围，不把监听成功当成代理成功，不把代理成功当成 Codex 业务成功。
