# 事实、载体与发布模板

## 1. 事实母版

| ID | 类别 | 事实内容 | 来源 | 来源位置 | 负责人 | 确认人 | 确认时间 | 状态 | 冲突/备注 |
|---|---|---|---|---|---|---|---|---|---|
| F001 | 时间/地点/人物/事项/结果/数据/引用 |  |  |  |  |  |  | 已确认/待确认/不采用 |  |

规则：

- 时间、地点、人物、事项、结果任一关键字段待确认，不得发布对应确定性表述。
- “准确”“据悉”“相关人士”不能替代来源。
- 正文中的数字、姓名、职务、地点和结果必须能回到来源位置。
- 公开来源记录发布主体、发布时间与获取时间；确认人未提供时标“未提供/不适用”，不得编造。私下确认记录实际确认人与时间，未知就标未知并判断是否影响采用。

## 2. 不确定事项表

| ID | 待确认事项 | 当前证据 | 不确定点 | 影响内容 | 处理决定 | 负责人 | 截止时间 | 是否阻断 |
|---|---|---|---|---|---|---|---|---|

处理决定只能是：删除、改写为非确定性说明、补证后采用、继续阻断。正文使用“待确认”时，必须与本表一一对应。

## 3. 内容逻辑链路

1. 目标受众和阅读场景；
2. 核心信息；
3. 发生了什么；
4. 谁、何时、何地、做什么；
5. 为什么重要；
6. 产生了什么结果；
7. 读者下一步行动；
8. 来源、备注或更正入口。

正文必备点逐项绑定 `F-ID`，避免排版时删除关键事实。

## 6. 发布门禁

- [ ] 关键事实均有可定位来源及适用的发布/确认记录；缺失字段如实标注，未伪造确认。
- [ ] 关键待确认项为 0，或已明确阻断发布。
- [ ] 正文、图片、二维码、联系方式和结果一致。
- [ ] 版权、肖像、隐私、商标、引用和敏感信息检查通过。
- [ ] 最终尺寸真实渲染无溢出、裁切、错位和低对比度。
- [ ] 独立评审问题已修订并复验。
- [ ] 发布物、验收截图和版本记录一致。

## 7. 活动资料修订（按需）

| 原位置/条款 | 当前依据与范围 | 新位置/新文案 | 关联载体/条款 | 实际处理及复验 |
|---|---|---|---|---|

局部修改可在简短记录中列源文件标识、允许修改项、实际差异和检查结果，不要求填写其余完整模板。详见 [event-handbook.md](event-handbook.md)。
