# 材料驱动的论文内容验收

## 研究类型与结构

先确认研究问题、对象、时期和材料能回答的范围；按用户原语言或明确目标写作。课程案例改为期刊稿时保留原题目/评分要求的约束，另存示范稿，避免悄悄替换已提交作业。

| 类型 | 可采用的组织 | 不应自动追加 |
|---|---|---|
| 实验/算法研究 | 引言、相关研究、方法、实验结果、讨论、结论 | 未执行的实验、假造消融、未经比较的先进性 |
| 企业/公共资料案例 | 问题、材料与方法、证据结果、解释与局限、结论 | 把 SWOT 当贡献，把定性讨论写成弹性估计 |
| 文献综述 | 检索范围与纳排标准、主题综合、争议与局限 | 未实际执行的系统检索、虚构文献或假造文献数 |
| 理论研究 | 问题定义、假设、推导、讨论 | 没有证明的定理、为了外观而添加实验 |

标题表达对象和实际研究问题，避免只写“公司分析”“方法分析”。摘要的背景、材料/方法、关键发现、结论必须能在正文中逐项找到；字数及是否结构式摘要由目标期刊决定。引言中的研究缺口需文献支撑，缺少同行评议文献时明确目前是案例/格式示范，不能宣称已具备投稿贡献。

## 证据账与引用

每个关键量或结论记录：`claim_id / statement / fact|inference|proposal / source_id / locator / period / unit / population / limitation / PASS|CAUTION|BLOCK`。来源账记录作者、日期、标题、原始网址/本地文件、页码/表号、核验状态。事实及推理的可核验位置不可空白。推理需记录前提与竞争解释；建议使用条件和未来时态，不能变成已实现收益。

使用公开财务材料时区分公司集团与业务分部、产销与零售注册、行业平均与公司价格、召回范围与确认缺陷数、费用与包含资本化的总投入。时期变化同时说明分母、单位、同比/环比和百分点，计算值须能从原始量重算。

按目标引用风格建立内文引用和条目双向对应，核对同作者同年份后缀、标题、日期、来源位置、URL/DOI。来源没有被实际读取或无法核验时记录状态，不编造元数据或期刊文献。需要新检索时使用官方出版源、原论文与可信索引；新加入文献须先读再写。同行评议文献与公司、行业、监管一手材料承担的论证任务不同，不能互相冒充。

## 内容验收表

逐项记录 PASS / CAUTION / BLOCK 与具体段落/证据，而不是只勾选“已自检”。

1. **问题与标题**：标题、摘要、结论回答同一个具体问题；标题没有超出材料范围。
2. **方法真实性**：声称用过的来源、检索、计算、实验、公式与实际执行相符。
3. **证据与口径**：数字有位置，推导能重算，相关性不冒充因果，组别与时期一致。
4. **学术定位**：相关研究与缺口有文献；贡献的强度与材料相符；不足列在稿外待办或正文局限中。
5. **段落逻辑**：每段有明确论点、证据、解释，结果、讨论、建议各司其职；方法承诺没有后文缺席。
6. **引用闭环**：所有内文引用有条目，条目被引用，作者年份后缀正确，没有占位引用。
7. **图表一致**：图/表被正文引用；数值、单位、样本和说明与正文及原材料一致。
8. **结论边界**：没有新增结果，建议未写成事实，局限足以解释材料不能回答什么。

缺失数据和引用放进工作记录，正式交付稿不能含 `[?]`、`[待补充]`、虚构作者、虚构单位或假 DOI。证据不足的稿件可以作为如实标注的初稿/示范交付，需准确说明尚不能支持投稿结论。

正文不写“保留原稿”“本轮生成”“验收通过”等制作过程；研究资料及其截止时间可以作为方法信息。用户要求的通用格式标签放在专门说明位置，内容审阅与渲染记录放稿外。

## 比亚迪回归案例

用于检验技能是否会重复真实错误，不能推广成所有论文的结构要求。

- 原稿 2.1 声称用了“2024 年报、2025 财务摘要、Reuters”，实际来源账是 2025 年报、2026 半年报、产销公告、IEA、欧盟文件和召回公告。应以实际来源重写方法，不能凭句子看起来学术就保留。
- 原稿承诺“经济公式和情景推理”，实际没有弹性估计、公式或完整情景计算。改为公开资料的描述性比较与定性经济解释；缺少价格和成本明细时保留不能估计弹性的局限。
- 利润率可由 40.254/777.102、32.619/803.965 重算，下降约 1.12 个百分点；不能用该变化单独证明价格竞争造成利润下降。
- 周转天数 79→109、经营现金流为正，支持资金占用解释，不能推出流动性危机。
- IEA 的平均价格和地区销量不是 BYD 价格、需求弹性或市场份额；183,211 辆召回范围不是现款缺陷率。
- 本例没有足够同行评议研究和识别设计，内容的证据忠实度可验收，期刊研究贡献仍为 CAUTION。格式通过不能升级这个判断。
