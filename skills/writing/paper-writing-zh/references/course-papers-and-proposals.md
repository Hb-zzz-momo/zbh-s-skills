# 课程论文与研究提案

本分支用于教师布置的论文、课程研究计划和定量proposal。沿用论文主技能的证据、引用和格式验收，不因课程名称不同复制技能或套用考试、实验流程。已有课程专属规范优先；仅有不可复用的执行差异或用户明确要求时增加专属适配。

## 1. 锁定作业契约

从真实材料确认课程、交付类型、研究问题、正文语言、篇幅、章节、允许数据与方法、引用规范和提交组成。按内容、版式、事实分别核对权威：教师题面/rubric管考核，指定模板管版式，原始材料管事实；用户要求与课程要求有差异时如实记录，不能声称教师已接受。

在项目已有QA位置维护简表；小任务可留对话，不另建资料库：

`要求ID → 来源文件/原文位置 → 明确要求|范例约定|作者设计|未知 → 正文位置 → 验证证据 → 状态`

- 没有rubric时不编评分权重、字数或满分结论；先完成有依据部分，只问会改变范围的关键缺口。
- 范例页数、示例样本量、例文变量和成员身份不自动成为要求。版式相似不证明课程考核已全覆盖。
- 核对原稿已有的方法与数据来源。把二手资料改成问卷、把描述统计改成SEM、把提案改成实证报告，都是实质设计变更；查已有授权，未获明确授权时保留基线、说明备选并向用户澄清，继续不依赖选择的工作。
- 用户要求优化时先找实际缺陷，不以新增章节、模型或篇幅作为改进证明。重要取舍在QA记录依据和成本。

## 2. 按阶段写作

| 类型 | 正文依据与时态 | 必须守住的边界 |
|---|---|---|
| 研究提案 | 已知背景用事实时态；采样、测量、分析写拟定方案 | 不生成实际N、均值、信效度、路径系数或显著性；不强求结果章 |
| 已完成研究 | 已收数据、实际计算与分析输出 | 实际方法和结果对应；未执行检验保留为局限或未来工作 |
| 公开资料/案例论文 | 可定位的二手数据或文档、适用的描述与解释 | 文档内容分析不能单独证明变量统计关系，更不能证明因果 |

提案摘要写问题、拟设计、预计交付及适用边界；预期产物可以是拟报告表项和判定规则，不能预写“假设均获支持”。有数据的论文则根据真实结果写摘要和结论。

## 3. 定量设计的对应检查

仅在当前作业涉及定量设计时使用；实际分析或实验执行转相应领域技能，不把写好方案当执行完成。

**共同检查：**

1. 研究问题、分析单位、目标总体、时期、数据来源和结果变量一致。购买意向、实际购买和市场销量是不同结果，不能互换。
2. 每项拟分析对应一条问题或考核要求，并符合变量类型、样本/数据可得性及课程资源。中介、调节、SEM、预测和子组分析都不是默认必选项；存在不可行承诺时降为条件分析或澄清范围。
3. 文献缺口、题项或数据来源有实际读取证据；“已有研究讨论过这个概念”不等于“直接采用了该文献的成熟量表”。

**问卷/一手数据分支：**

`研究问题/假设 → 构念角色 → 操作定义 → 题项来源/自编或改编状态 → 计分 → 纳入条件与采样 → 拟检验/报告量`

- 定义、问卷、假设表、方程、图和计分清单逐项核对。题项不得直接混入被解释结果；反映式/形成式选择需概念依据，不能仅靠软件默认。
- 样本数与配额标清拟定依据和适用范围；总体样本规划不自动保证交互、间接效应或子组功效。不能假装完成了功效模拟。
- 筛题必须有可判定标准；活动频次或真实极端意见不是注意力题的错误答案。缺失、异常与退出规则应具体、可执行，且不靠核心自变量筛人来改善结果。
- 含交互时检查两主效应、条件斜率、间接与总效应是否对应。复杂派生量要能从方程逐步得到；横断面中介仍受时序和混杂限制。
- 招募权限、语言覆盖、知情同意、伦理审批/豁免、真实联系渠道和数据保管以实际条件为准；提案不能冒充已批准或可立即发放的问卷。

**二手数据/文档分支：**

- 建立来源、时期、分析单位、变量/编码规则与可得字段的对应。没有个体数据就不能套个体量表信效度；只有少数汇总点不能据此承诺复杂结构模型。
- 定量内容分析需说明文档如何纳入、编码、计数及复核；统计关系需要可匹配的观测与可执行的检验。缺失数据时限定为描述、文献综合或待收集计划，不补造相关/因果结果。

## 4. 可行性、验收与增量复验

在润色和大规模排版前检查招募渠道、数据权限、技能/工具、时间和每项分析的产出，避免把课程提案写成无法执行的研究项目。方法扩展超出原任务时保留为明确备选，不静默加入主方案。

验收分别回答：要求覆盖、方法与阶段一致、数字/引用真实、模板格式、缺口与完成声明。沿用既有独立评价规则；缺评分表就保留课程整体符合性的未知，不能用内部方法PASS代替教师认可。

续做先核对当前成品与已验收证据。无实质缺陷时可以保留正文，用要求映射证明复核结果，不为“调用了新分支”强制重写。发生修改时仅修影响范围，按文件、文本、分页和图表变化选择必要复验；继承旧页审阅须提供当前等价证据，不能只凭文件名或旧PASS。
