# 迭代日志

## 2026-10-09 教程逐项覆盖与修订闭环

- **触发反馈**：用户要求先覆盖全部实验教程和要求，再将本次执行缺口写入相关 skill。
- **根因**：概括式材料盘点和正文自检漏掉图中限制、关联教程、独立子步骤及提交示例；修订判据后缺少产物同步检查。
- **修改内容**：读取与覆盖规则共用主流程；按原编号记录来源、实际操作、证据和报告位置；区分可选、条件和冲突；成稿从原教程反查；规则变更保留旧记录并重跑、取证及更新交付包。
- **影响范围**：材料核对、报告生成与自检、排错复验；未增加任务模式或强制扩展用户范围。


## 2026-10-10 机器学习教师代码边界

- 触发反馈：用户明确要求作业填空外完全按教师代码，不额外补代码；最终 HTML 必须在 Jupyter 中全量执行。
- 根因：旧规则推荐补 head 和诊断格，与最新要求冲突。
- 修改内容：替换旧推荐，路由到机器学习教师代码及 HTML 回读复验规则。
- 影响范围：机器学习报告模式，其他课程依其本课规则。
- 授权：用户本次直接说明该持久规则，延续上一轮写入相关 skill 的明确授权。

- 影响范围：所有有明确步骤的课程实验；本次不修改报告、算法或模式结构。
- 授权：用户本次直接要求修改skill并明确给出规则，按该授权执行。

## 2026-10-13 AI位置核对默认必做与Web踩分点

- 触发反馈：每次实验报告交付最后都要直观标出AI辅助/AI完成声明的位置；Web须按教师所有踩分点执行，包括注释率。
- 根因：位置核对仍有“用户要求时”的条件；“只输出正文”容易吞掉交付说明；Web阶段摘要不能证明全部评分条款与逐模块注释已核验。
- 修改内容：所有报告默认交声明位置表、实际参与表及有声明时的编号标注预览，最终回复展示原文与页码；零声明不等于零参与，去AI味不删除真实披露。Web路由到全部教师踩分点和源码/最终正文逐模块注释核验，保留其他课程边界。
- 授权：用户本次直接要求优化全局实验报告Skill，既有自动同步授权继续适用。
- 验证：三份入口基础检查、本包结构与链接、42项既有单元测试通过；原始输出见主工作流 `tests/results/ai-position-web-rubric-20261013-*`，不等同未来模型行为或课程报告验收。

## 2026-10-13 独立审查与评分循环

- 触发反馈：用户要求2号subagent独立检查，3号另一subagent独立评分，1号修改后重新交审，至少五轮或有依据满分。
- 修改内容：三处实验报告入口统一路由到独立协议；逐项检查真实评分点执行、原顺序、完整详细程度、截图完整/重点红框、注释和美观；记录真实代理身份及本轮输入摘要，最终交付与末轮审查/评分版本一致。
- 来源与边界：红框与五轮为用户新增要求，不能冒称教师规定；未知权重的内部评分明确标注，不能据自评100跳过五轮；AI心得草稿与待本人修改状态继续如实记录。
