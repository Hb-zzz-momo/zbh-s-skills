# 实验报告独立自检与评分循环

适用范围：本用户的实验报告生成、修订及交付。用户已明确要求并持续授权在此范围真实调用两个子代理，避免作者检查自己的报告；不扩展到无关任务或外部发布。优先遵守本次用户的新指令及课程原件。

## 固定职责

| 角色 | 执行者 | 职责与写范围 |
|---|---|---|
| 1号 | 主代理/作者 | 执行实验、采集证据、写报告、落实建议、重跑受影响操作、重新导出和打包 |
| 2号 | 独立审查 subagent | 只读原件、真实代码/日志/原图及最终报告；仅写自己的逐项审查记录，不修改被审材料 |
| 3号 | 另一个独立评分 subagent | 独立依据评分标准复核并评分，给出具体扣分依据和修改建议；仅写自己的评分记录 |

2号和3号必须是与1号不同、彼此不同的真实代理身份，不得由1号换名字、模拟对话、自填评分或让同一个子代理兼任。首次委派使用不继承作者结论的新上下文，提供原件、目录和核查任务，不提供“已经通过/应该满分”等诱导。3号在2号审查后进行评分；可读2号的问题清单，但必须自行读取评分依据与被评分成品，不复制作者的自评分。跨轮可复用两位代理，保持各自只读边界。

工具不可用或代理失败时如实记“独立审查/评分未完成”，可以继续修复已知问题，不把作者自检当作替代，也不虚构轮次或满分。

## 每轮闭环

1. 1号冻结本轮Word、PDF、源码/证据批次及SHA256，明确本轮输入、改动与上一轮建议；审查时不并行修改这些输入。课程原件以路径、页码及摘要锁定。
2. 2号从原件逐编号审查下表，记录通过、缺口、未核验及实际文件/页码。脚本结果是辅助证据，不能替代独立查阅和视觉检查。
3. 3号按教师提供的评分标准逐项给出得分/满分、扣分原因、证据及可执行建议，并复核2号问题。没有完整权重时，采用明确标注的“内部复核评分”，先说明权重的来源或设定；未知教师算法、认可状态和正式成绩保持未知。
4. 1号逐条记录“采纳并修改 / 有证据不采纳 / 待本人或教师确认”，保存前后版本。修改源码、配置或实验判据后重跑受影响流程；只改图注、标注或格式时无需重复未受影响实验，但须核对版本、重新导出并审阅受影响页面。
5. 更新原图/标注副本的对应关系、页码、措辞自检记录与文件摘要，将新版本再次交2号，再交3号。最后交付版本必须与最后一次独立审查及评分的摘要一致；审查后再改正文或图片必须再审，不用旧结论背书新文件。

默认完成至少五轮真实的“2号审查→3号评分→1号落实→再次独立复核”，或者依据完整且可核验评分标准确认满分后提前结束。内部估分达到100、作者认为无问题、工具退出0均不自动满足提前结束条件。每轮均要有实际代理、输入摘要、检查记录、评分及建议处理记录；稳定版本可进行复核，但必须记录实际查验内容及为何无需再修改，不能重复粘贴评语来凑五轮，也不为制造轮次而虚构问题或改动。

五轮后仍有必做缺口继续完成授权范围内的修复；只有确需本人体验/修改、教师认可或缺少真实材料的事项单列待办，不伪造经历或为了满分隐藏差异。用户授权的AI心得草稿可完成并交付，待本人修改状态不冒称通过教师原创/禁AI要求。

## 2号逐项检查

| 检查面 | 必须查到的证据与判据 |
|---|---|
| 评分点与真实执行 | 当前通知、指导书、模板、课堂补充的每一评分点→实际操作→状态/数据→原始证据；正常、边界、错误路径按本题要求覆盖 |
| 顺序与要求 | 原任务/子步骤/代码/输出顺序一致；不漏、合并、重排或用自创扩展替代；等效操作与未执行步骤如实分列 |
| 截图完整 | 每个必做功能及独立状态有对应真实应用截图；无关、重复、加载中、旧图冒充新操作均不算；长结果分段完整且图注说明范围 |
| 截图重点红框 | 逐张检查报告中的实验截图至少有一处与本图证明对象相符的重点红框，框住实际按钮/输出/字段/状态，不能只框整图或只用与证明对象无关的红框充数；保留未经标注原图，红框副本有来源和坐标，不能遮挡或改写结果。教师明确要求原图时按其要求提交，另交标注核对副本 |
| 内容完整详细 | 每小题有前提、操作、关键实现、结果和解释；问题全部回答；核心代码/配置按课程要求完整且可复制，附件或截图不替代正文；具体版本、参数、状态和数据与证据一致 |
| 注释与质量 | 源码及最终Word按语言/模块检查注释率和有效性，识别字符串/URL，核对状态边界、职责、输入绑定、资源与异常；不靠通用注释或别的模块拉高总比例 |
| 格式与美观 | 继承指定模板，字体、字号、编号、表格、图片比例、打印尺寸清晰度、图注、段落与分页协调；无裁切、孤立标题/图注、溢出、无意义空页；首轮看全部页面，后续仅当其他页图像摘要一致才可复用其审查 |
| 措辞与归属 | AI说明与间接说明清零（含图片替代文本、脚注、属性、元数据），无“本人”过度强调，无状态/流程/不确定性元叙述；逐句读起来自然、与个人撰写无异；实际操作来源只记内部记录；最终Word/PDF、源文件、证据和ZIP对应同一版本，教师成绩栏不填内部估分 |

以上为用户新增审查要求，不把红框或五轮解释为教师原件已规定，也不新增课程未要求的实验功能。

## 3号评分与建议

优先使用当前教师细则的维度、分值、阈值和条件；历史评分维度仅在明确标注“历史来源、用于内部复核、当前教师权重未知”的前提下参考。每个维度列满分、得分、证据、扣分点、最小可执行修订及修订后的验收方法。问题须能定位到页/图/源文件/操作，区分已实测、原图不足、事实待核实和待本人完成。

不得承诺教师正式满分、推测AI检测器通过、以重复截图或堆字刷分，或为消除扣分编造亲手经历、实测输出、截图和许可状态。评分记录放在随附审查材料，不填入正式报告教师评语/成绩栏。

## 每轮记录与最终出口

在当前实验已有证据/修订目录下维护 `独立审查/round-01` 等：本轮输入与摘要、`agent2-review`、`agent3-score`、1号建议处理与修改记录。记录真实代理身份、检查时间、证据、状态、各维度评分/来源及下一轮入口。正文不塞入制作流水账。

交付展示完成轮数、最终两份独立结论、评分性质及分项/总分、主要修订、仍存缺口，以及措辞自检结论（自然度、个人撰写无异）。轮次、最后输入、报告和包摘要保持一致；不能仅凭作者审核、包校验或子代理一句“通过”宣布完成。
