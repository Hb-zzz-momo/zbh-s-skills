# 数据挖掘与机器学习：教师讲义、Jupyter 执行与 HTML 交付

## 依据和优先级

适用于以教师 Markdown、Notebook 或 HTML 讲义为模板、提交 HTML 的机器学习实验。本实验有专属skill时先遵循专属skill；本课程规则和通用skill只补充未规定事项，本次用户明确要求始终优先。全文读取当前讲义、作业和教师评测要求，再按需读[模板完整保留规则](../template-lecture-fidelity.md)和[原始输出规则](../notebook-output-fidelity.md)。旧报告仅作历史记录，不能作为新实验源代码或模板。

## 教师代码原样执行（硬要求）

- 使用本课当前实验原讲义。保留全部理论、标题、身份字段顺序、代码、原单元边界、公式、表格、图片及原顺序，不省略、合并或重排。只有 Markdown/PDF 导出件时按原代码围栏恢复代码单元并记录来源行号；不得声称已经知道缺失的原 ipynb 单元总数。
- 除讲义明确要求自行编写的作业代码外，完全按教师代码执行。填空只在原空格完成，保留函数名、变量名、算法、原参数及调用过程。不自行补充诊断格、`.head()`、`shape`、`print()`、随机种子、预处理、模型、评价指标、交叉验证或绘图；不得另写外部模块替代原代码。原讲义已有这些代码时全部照常执行。只有用户后续明确允许扩展时，才先完成原实验，再单独编写和执行授权范围内的扩展单元，不修改教师原格；其他实验的扩展许可不自动迁移。
- 无显示输出的导入、赋值或函数定义照常运行，只在证据台账记录执行；正文不加显示表达式、输出区或“已执行”“当前单元无显示输出”等说明。有输出的格完整展示 Jupyter 原生结果，不能人工填写数字、改写表格、重新绘制输出图或使用讲义旧输出。
- 原绘图单元分别执行并展示，不合并成另一张图，默认不额外增加绘图代码。作业需要自行编写时，只完成题目要求的内容和输出；额外图表只在用户明确允许扩展的范围内另做，不替换原图。
- 不新增AI注释或面向用户的制作、对照、带练说明，已有这类注释在完成版清理。正式代码只保留教师原有的有效技术注释，以及作业明确要求学生编写的必要注释；不为显得详细添加解释性注释。填空提示在填好后清理，原件及清理记录留在证据中，不把该规则扩大成删理论、步骤或教师有效注释。

## 教师原代码报错

警告同样按[执行输出与完成声明规则](../verification-completion.md)判定，先区分参数弃用、环境问题与影响收敛/指标的诊断。核对实际内核、解释器及教师代码的兼容版本；不能因模型返回分数就宣布全部通过。严格保留教师代码时优先固定隔离兼容环境，不补过滤警告的格、不手动移除输出；仍存在且已解释的非阻断警告明示为CAUTION。

先在真实 Jupyter 内核执行并保留报错，检查实际数据、维度、依赖和课程环境。优先匹配可用的教师环境，不静默换算法、参数或删除原格。

当严格保留教师非填空代码与全量正确执行发生冲突，向用户说明具体原格、错误和最小改动。已有明确修复授权则继续；没有授权且用户明确要求代码不变时，取得授权后才修复。授权后在原单元作必要的最小修正，保留原代码、失败结果、差异和授权依据，不加替代执行格。从干净内核重跑全部代码，并在交付说明中列出修复；不得声称教师原代码未经修正就已全部跑通。

## 执行、导出与最终 HTML 复验

1. 盘点并备份原 ZIP、讲义和旧报告，核对源文件及数据哈希。逐格记录来源、类型、顺序、填空和允许清理的提示；正文仍沿用原编号。
2. 填写已知身份和原作业空格，保存包含全讲义的 Notebook。必须在真实 Jupyter 中从干净内核按讲义顺序逐格执行全部代码；可通过界面或 nbclient/nbconvert 驱动该内核，用户明确要求界面时使用界面。能显示结果的原格全部跑出并展示真实结果，所有原图实际生成；导入、定义或赋值格也执行，没有显示输出就不放输出区。如实记录实际方式，不把自动逐格执行称作界面点击，不用普通脚本退出成功冒充Jupyter执行。
3. 保存未经后处理的已执行 ipynb、完整 MIME 输出、图片字节、连续执行编号、每格输入/输出哈希、stdout/stderr、异常、时间、依赖及工作目录。正式正文用同份快照的原生 nbconvert 输出替换旧输出；不修改输出内容。
4. 在原讲义 HTML 结构中填回执行代码及结果；只有 Markdown 时继承其原文字和顺序，用原生 Notebook 导出结构。图片内嵌，检查公式、表格、长代码和模型表示。制作日志与状态说明放证据目录，不混入报告正文。
5. **最终交付HTML必须再放入真实Jupyter执行链路全量核验。**能取得教师读取/执行HTML的评测脚本时，实际用该脚本检验最终HTML并保留日志；未取得时，从最终HTML输入代码区恢复全部代码，保留原格边界和顺序，核对与已执行输入一致，生成复验Notebook，用新的干净Jupyter内核从第一格运行到最后一格。使用最终HTML所在目录及正确相对数据路径，全部输入代码必须可读取，不藏在截图或外部模块。全部代码实际执行，能显示结果的格得到真实结果，原图全部生成；保存最终HTML哈希、代码比对及执行证据。不能只复跑生成脚本或原Notebook，也不能手填结果；未解决异常列为缺口，未使用教师脚本就不能声称官方评测通过。
6. 教师原随机搜索、决策树等未设种子的过程保留原设置。如实记录两次执行的合法差异，不添加种子、不重试挑优、不要求随机结果字节一致；分别检查代码一致、运行完整、结果有效及本次正文与首次输出对应。
7. 完成后做内容和格式全量自检：按讲义逐项反查完整代码、原顺序、作业、结果和图片，核对原生输出来源、数字与结论、无额外代码及无AI注释；逐页查看最终HTML的标题与身份、字体、公式、表格、长代码、图片、裁切和占位残留，不能只看首页。源码/输出一致性、数学正确性、模板覆盖及最终渲染分别判定。留下过程记录、复现说明和唯一最终HTML，源代码、日志和旧版放证据目录；未核验项不能写成已通过。

## 结果核对边界

独立核对脚本可在证据目录检查数据计数、维度、缩放范围、预测条数、准确率、梯度或代价，但不能把检查代码插入实验 Notebook/HTML，也不能用其计算结果替换 Jupyter 输出。没有要求的混淆矩阵、分类报告或额外曲线只可作为内部核对；仅在用户明确允许扩展时，才在授权范围内另作正式扩展内容。

实验四已核对的原版示例用 70%/30% 划分，末尾作业用 75%/25%，MinMaxScaler 只在训练集 fit、测试集 transform；示例和作业各按自身要求，不能统一改成同一个比例。这仅适用于该讲义版本，其他实验重新读题。未指定随机种子的作业不要为追求高分挑选；身份和班级也不得猜测。
