# 实验交付验收清单

仅检查本次适用项。不适用需有理由，未知不能默认为通过。

## 1. 材料与范围

- [ ] 已区分课程、实验编号和版本，没有同名实验串用。
- [ ] 已完整读取当前全部教程、要求、相关数据与源码；PDF/PPT逐页核对截图、标注、正反例、脚注及提交示例，没有只靠文本提取或旧记忆。
- [ ] 已核查影响本实验的关联教程与版本，失效链接、缺失许可或材料有真实核查结果及补做办法，没有询问材料已给出的信息。
- [ ] 已按教程原编号逐个子步骤建立覆盖表，记录来源页码、实际操作、判据、证据位置/批次、报告位置、交付位置与状态。
- [ ] 必做、可选、条件触发及冲突解释分开；用户已选入本次范围的选做项已纳入验收。
- [ ] 已读取指定模板；局部修改有明确边界。
- [ ] 已查本实验专属skill，有则第一遵循；课程/通用规则只补缺，没有覆盖专属规定。
- [ ] 环境替代的未覆盖要求和认可状态已说明。

- [ ] 有本课模板已使用本课当前实验原件副本，没有套用其他课或通用模板。
- [ ] 已逐项核对全部原内容、代码、公式、表格、图及题注，未删减、合并或调整原顺序；新增内容单独标识。
- [ ] 有讲义按全部原步骤执行；Notebook/机器学习实验保留所有原单元及顺序，全部代码逐格实际执行并显示真实输出，包括数据预览和中间结果；没有只跑填空或替代脚本。
- [ ] 机器学习新增代码仅展示已有数据或计算结果，放在对应原格后并保留原格边界与相对顺序；其他有明确步骤的实验未默认增加代码、输出表达式、单元或功能；题目所需的自行编写已完成，延伸扩展有用户明确授权、独立位置及真实执行证据，未替代原要求。

## 2. 教学与执行

- [ ] 机器、用户、终端、目录及输入输出明确。
- [ ] 命令可复制，变量已说明，Shell和路径没有混用。
- [ ] 每个教学模块包含直观例子、必要知识、验证及逻辑链路。
- [ ] 核心代码来自当前工程，未绕过课程要求，未覆盖无关改动。
- [ ] 权限、删除、网络暴露等风险操作没有越过授权边界。

## 3. 结果与证据

- [ ] 已检查每格全部原生输出及完整 stdout/stderr、驱动、构建/导出日志；警告、异常和未解释 stderr 均有分类、原因、影响及当前复验依据，没有只统计error或只看日志末尾。
- [ ] 来源一致与结果正确分别验收；未分类诊断、必做未验证不能通过，仍存在的非阻断警告明确降级；题目预期警告/错误有原要求依据，未过滤或删改输出。
- [ ] 每个必做要求有验证条件、执行状态和证据状态。
- [ ] 证据对应当前实验与运行批次，没有借用示例或他人截图。
- [ ] 已区分编译、本地测试、用户环境、官方评测与报告提交状态。
- [ ] 数据/查询/图表关键值可回溯；未测指标没有编造。
- [ ] 机器学习教师代码按讲义在干净Jupyter内核全量执行，原格可显示的结果及图均真实产生，新增纯展示格也全部实际执行，无其他未经授权的额外代码或AI注释；最终HTML（含展示格）已由教师脚本或代码回读后在新Jupyter内核全量复验，未取得教师脚本时如实说明。
- [ ] 问题记录区分已证实原因、推断、建议修复和实际复验。
- [ ] 判据独立从原材料确认，检查图中限制与边界例，没有用实现与校验一致或零异常代替题目符合性。
- [ ] 规则/代码/配置变化后保留旧输入与结果，重跑受影响作业并同步校验、最终状态截图、报告与打包结果，没有倒填历史运行。
- [ ] 密码、密钥、令牌等已在分享副本中妥善脱敏。

## 4. 报告与文件

- [ ] 正式报告保留当前模板结构、样式和固定栏目。
- [ ] 旧课程名、标题、日期、用户名、图片、图题和结论已清理。
- [ ] 正文以实验操作、参数、现象和分析为主，没有小白教程口吻、聊天进度、状态/制作/提交说明或反复强调“本人”的句子；实际操作来源与过程分工记内部记录，不进报告正文。
- [ ] 已按课程规则分别检查代码、配置、命令和结果的呈现形式；要求文本代码的课程未被截图代替。
- [ ] 截图或规范图位与说明形成证据链，缺失项集中列明。
- [ ] 每张截图已放大检查画面干净：无Computer Use发光指针、控制浮层或鼠标指针；发现即重截，不涂改遮盖。
- [ ] 成稿后从完整原教程逐项反查代码、运行结果、截图、正文与交付目录，未用正文自检和格式检查替代。
- [ ] 模板要求写清搭建时，正文已有真实前提、具体操作、配置和验证，未用环境摘要或脚本路径替代。
- [ ] 模板固定的知识点栏目每条对应一个具体疑问、解答与实际验证，配真实验证截图和运行证据，结论落在结果是否满足要求上；正文不写AI参与说明。
- [ ] 报告正文AI说明与间接说明为零（含图片替代文本、脚注、隐藏属性、元数据），“本人”无过度强调，无状态/流程/不确定性元叙述。
- [ ] 已交独立agent复核措辞是否自然、与个人撰写无异，结论记内部记录；数据、代码、截图、结果未因叙述清理被改动。
- [ ] 措辞自检对应去AI味及排版后的最终版本；分页/原文变化后已对受影响段落复验，未完成时没有宣称报告交付完成。
- [ ] Web报告已从当前教师原材料拆出全部踩分点，含条件、加分/扣分、正文与源码注释、结果/分析、心得与提交；未用阶段名称或单一注释总比例替代逐条覆盖。
- [ ] Web注释统计同时覆盖交付源码与最终Word正文，并按语言/模块列非空代码行、含注释行、比例及口径；质量逐模块核查，短SQL或重复注释未掩盖其他模块缺口，教师阈值有当前来源。
- [ ] Web已全文读取并逐页核对用户指定的《实验前先阅读》原件，按Web规则W-N01—18及六块标题子项逐条回填实际操作、证据与最终报告位置，未只检查注释比例。
- [ ] Web六块内容有实际可识别标题，命名、适用功能截图、可复制代码、结果文字、心得字数及具体细节分别验收；原件没有规定的张数/计分算法未自行杜撰。
- [ ] Web心得按用户最新授权先生成至少80字且有真实实验细节的完整草稿，再由本人结合想法修改；起草与修改状态记内部过程记录，修改后重查事实/字数，未提供本人文字不阻止先交草稿，未借同学正文或编造经历。其他本人文字要求保留，去AI味及本人校对未被冒称独立起草。
- [ ] 文件已真实生成并可打开；未渲染项目没有声称视觉已通过。
- [ ] 缺少必须证据时标记“待补充版”，未声称可直接提交。
- [ ] 最终包符合教师目录示例、相对层级与命名；重新解包核对需要交付的源码、校验/复现文件、依赖和可用参数说明。
- [ ] 包中每个正式入口及复验文件别名均与当前验收版本哈希一致，历史文件单列；ZIP打开或CRC通过没有代替内容与版本核对。
- [ ] 已按学生隔离要求检查提交文件名、正文、图片、批注与元数据；未借用他人运行结果。
