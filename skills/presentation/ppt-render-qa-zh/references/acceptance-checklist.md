# PPT 验收清单

## 内容

- [ ] 页面顺序、标题、正文、备注和引用完整。
- [ ] 无 lorem/ipsum/xxxx/待替换等占位文本。
- [ ] 数据与正文一致，来源可追溯。

## 几何与视觉

- [ ] 无越界、裁切、遮挡、拉伸和错位。
- [ ] 页面安全边距、列对齐和间距一致。
- [ ] 字体替换后层级与换行可接受。
- [ ] 图表、标签、来源和注释可读。
- [ ] 连续页面有节奏变化，信息密度不过山车。
- [ ] 每页只有一个主要结论与一个主要视觉焦点。
- [ ] 每条有向连接都能从可见箭头头部判断方向，端点落在明确节点边界；闭环、跨行和径向连接具有必要的转换/约束标签。
- [ ] 箭头不终止于空白、不被后绘制节点遮挡、不穿过文字，连线标签与实际方向一致。
- [ ] 每种卡片家族中最密卡片的最后一行与容器底边保留可见内边距；不得以 `fit/shrink` 或 OOXML 无越界替代视觉检查。

## 交付

- [ ] 已完成至少一轮修复复验。
- [ ] 代表页覆盖所有高风险布局家族：箭头密集页、最高文本密度卡片/表格页，以及封面和收束页。
- [ ] PPTX、源码、素材、渲染图和 QA 报告对应同一版本。
- [ ] 记录实际渲染后端与机器依赖。
