# PPT 布局语法

| 家族 | 适用任务 | 主体结构 | 风险 |
|---|---|---|---|
| hero | 封面、章节、结论 | 大标题 + 单一主视觉 | 正文过多 |
| split | 观点与证据、前后对比 | 40/60 或 50/50 双栏 | 两栏权重相等无主次 |
| process | 流程、机制、架构 | 有方向的节点与连接 | 节点过多、线穿文字 |
| data-focus | 单一数据发现 | 结论标题 + 主图表 + 注释 | 多图抢焦点 |
| comparison | 方案权衡 | 维度对齐的比较区 | 三列卡片模板化 |
| timeline | 阶段、计划、进展 | 时间轴 + 里程碑 | 文字密度过高 |
| evidence-board | 多来源证据 | 主张 + 2–4 条异质证据 | 卡片同质化 |
| summary-action | 总结与行动 | 结论层级 + 明确下一步 | 口号替代内容 |

连续页面可以共享家族，但必须改变信息构图或视觉焦点；不要靠随机换位置制造“变化”。
