# PPTX 构建常见故障

| 故障 | 原因 | 处理 |
|---|---|---|
| Office 打开修复提示 | 无效 OOXML 或媒体关系 | 用新文件名重建；模板编辑走安全打包工具 |
| 中文字体替换 | 字体未安装或名称不一致 | 使用回退链并真实渲染 |
| 标题被裁切 | 文本框高度不足、换行或字号过大 | 缩短标题或增加高度，不盲目缩到不可读 |
| 图表标签溢出 | 类别过多或字号过小 | 聚合类别、改图表类型或拆页 |
| 图片拉伸 | 未按比例裁切 | 使用 `sharp` 或等比 contain/crop |
| 组件对齐漂移 | 页面内硬编码 | 统一主题与布局函数 |
| PPTX 已生成但不可交付 | 未真实渲染 | 进入 `ppt-render-qa-zh` 完成修复复验 |
