# PPT 叙事类型

| 类型 | 核心问题 | 推荐主线 | 主要证据 |
|---|---|---|---|
| 课程汇报 | 是否理解并能解释主题 | 问题 → 概念 → 例子 → 练习/结论 | 教材、案例、演示结果 |
| 学术答辩 | 研究是否必要、可信、有贡献 | Gap → 问题 → 方法 → 实验 → 局限 → 贡献 | 文献、实验、统计、消融 |
| 创新创业路演 | 是否值得支持或投资 | 趋势 → 痛点 → 方案 → 壁垒 → 市场 → 进展 → 请求 | 市场、客户、验证、财务 |
| 商业提案 | 是否批准或采购 | 现状 → 损失 → 方案 → 收益 → 风险 → 实施 | 成本、收益、案例、计划 |
| 产品发布 | 为什么现在选择该产品 | 场景 → 新体验 → 能力 → 证明 → 可用性 | Demo、性能、用户证言 |
| 技术方案 | 是否采用并允许实施 | 约束 → 架构 → 链路 → 权衡 → 验证 → 迁移 | 指标、原型、风险、回滚 |
| 数据报告 | 数据说明什么、该做什么 | 问题 → 口径 → 发现 → 原因 → 行动 | 原始数据、方法、区间、限制 |

先依据听众决策调整顺序，再选择 archetype；不要把表格当固定目录。
