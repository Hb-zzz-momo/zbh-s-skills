# 经验沉淀规则

## 必须同步的二级入口

- 新增或删除 skill 后，同步 `skills/README.md`。
- 新增实验 step 后，同步对应工作流或接班手册。
- 新增项目根配置后，同步 README、`.gitignore` 或项目说明。
- 修改整体推进路线后，同步工作流细化和 tracing。

## 问答后的记录习惯

- 每段关键问答后，提炼 Q&A 总结。
- 如果是机制解释，加入名词速览和英文术语中文翻译。
- 如果是实验结论，写清数据、指标、对照、结论和下一步。
- 如果是问题修复，写清背景、原因、修复、验证和规避。

## 接班优先级

三层 v2 项目中，问答文章保存解释，影响启动判断的变化同步 records 和总览。通用员工经验为 agent scope，项目身份和实验授权为 project scope，机器能力为 machine scope。跨电脑核验 seal 和来源，不把本机写入称为远端同步成功。

1. 让新 AI 知道项目主线。
2. 让新 AI 知道当前冻结版本。
3. 让新 AI 知道哪些方向已经失败。
4. 让新 AI 知道下一步先做什么。
