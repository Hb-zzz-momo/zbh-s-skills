# 科研图质量验收门

## Gate 0: 事实边界

- [ ] 图中所有数据、样本量、P 值、时间、剂量、显著性都来自用户或真实数据。
- [ ] AI 没有添加未经确认的实体、标签、结果或文献结论。
- [ ] 概念图和结果图边界清楚，没有把概念图说成实验结果。

## Gate 1: 图意清晰

- [ ] 3 秒内能看出图的核心信息。
- [ ] 读图顺序明确：左到右、上到下、中心到外层或面板顺序。
- [ ] 复杂图已拆成 panels，没有把整篇论文塞进一张图。
- [ ] 重要关系用箭头、层级、颜色或分组表达清楚。

## Gate 2: 科学准确

- [ ] 机制图箭头方向正确。
- [ ] 抑制、激活、结合、转位、反馈等符号一致。
- [ ] 实验流程输入、处理、输出顺序正确。
- [ ] 模型架构和数据流没有把训练、推理、评估混在一起。
- [ ] 网络图来自真实节点/边或明确标注为概念网络。

## Gate 3: 图表规范

- [ ] 轴标签包含单位。
- [ ] 误差线类型在 caption 中说明。
- [ ] n 值、统计检验和显著性标注清楚。
- [ ] 不使用 3D 柱状图、伪渐变、阴影等会扭曲数据判断的样式。
- [ ] 连续色图使用 `viridis`、`cividis` 等感知均匀 colormap。

## Gate 4: 可读性

- [ ] 最终尺寸下所有文字可读。
- [ ] 没有标签重叠、截断、贴边、错别字。
- [ ] 图例不遮挡数据。
- [ ] 面板标签 A/B/C 一致且位置稳定。
- [ ] 海报图远距离可读，幻灯片图投影可读。

## Gate 5: 可访问性

- [ ] 色盲友好，不依赖红绿唯一编码。
- [ ] 灰度模式下仍能理解主要结论。
- [ ] 对比度足够，背景不过度花哨。
- [ ] 关键类别有颜色以外的冗余编码，如线型、形状、纹理。

## Gate 6: 输出与复现

- [ ] 数据图保存绘图脚本或 notebook。
- [ ] 结构图保存 Mermaid/TikZ/Graphviz 等源文件。
- [ ] AI 图保存 prompt、参考图、输出图和迭代说明。
- [ ] 投稿图导出 PDF/SVG/TIFF/PNG 中的合适格式。
- [ ] 最终 caption 解释了所有缩写、颜色、符号和统计含义。

## 常见失败与修复

| 失败                         | 修复                                              |
| ---------------------------- | ------------------------------------------------- |
| AI 图文字乱码或拼写错误      | 减少文字，后期用矢量编辑或 PPT/Illustrator 加标签 |
| 机制关系不准                 | 回到节点-边表，先画 Mermaid 草图，再生成          |
| 海报图太密                   | 拆成 2-3 张，每张 3 个元素以内                    |
| 数据图像很漂亮但数值不可追溯 | 丢弃 AI 结果，用代码重画                          |
| 多面板风格不统一             | 统一字体、线宽、色板、面板尺寸和导出参数          |
| 色彩好看但灰度不可读         | 增加线型、形状、纹理或直接换 Okabe-Ito palette    |
