# 科研图类型与路由

## 路由原则

先判断图的证据属性：

- **真实数据图**：必须用代码或已有图生成，AI 只做风格统一和标注辅助。
- **结构关系图**：先用 Mermaid/Graphviz/TikZ 锁结构，再视需要 AI 精修。
- **概念示意图**：可用 AI 生成，但必须锁定实体、关系和不可编造项。
- **已有图片复现**：先拆解参考图和交付等级，再选择视觉稳定版、固定背景版或逐元素可编辑版。
- **展示传播图**：可更强调视觉吸引力，但不能暗示不存在的实验结果。

## 常见图型

### 数据结果图

包括 line、scatter、bar、box、violin、heatmap、UMAP/t-SNE、survival、ROC、volcano、forest、multi-panel figure。

路线：

1. 读取真实数据或用户给定结果。
2. 用 Matplotlib/Seaborn/Plotly 生成。
3. 按期刊尺寸、DPI、字体、色盲 palette 调整。
4. 导出 PDF/SVG 和 PNG。
5. 写 caption，说明 n、误差线、统计方法和显著性。

### 机制通路图

包括 molecular mechanism、signaling pathway、metabolic pathway、gene regulation。

路线：

1. 列出节点：分子、蛋白、细胞器、细胞类型、处理条件。
2. 列出边：激活、抑制、转位、结合、裂解、磷酸化、反馈。
3. 确认空间层级：膜、胞质、线粒体、细胞核、组织层。
4. 生成 prompt 或 Mermaid 草图。
5. 验收箭头方向、节点拼写、层级位置和负反馈。

### 实验流程图

包括 wet-lab workflow、测序流程、样本处理、统计分析、CONSORT/PRISMA。

路线：

1. 先写步骤表，包含输入、处理、输出。
2. 每步不超过一个动作。
3. 复杂流程拆成 panels。
4. 若用于论文方法图，优先白底、扁平矢量、清晰标签。

### 系统架构图

包括模型架构、数据流、软件架构、pipeline、云服务、IoT、机器人系统。

路线：

1. 锁定模块、接口、数据流、控制流。
2. 用 Mermaid/C4/block diagram 建源图。
3. 若需要视觉化，再用 AI 做 clean vector 或 isometric technical。
4. 若需要复现已有架构图，必须额外列出图标、表格、连接标签、底部能力区和图例区，按 `image-reproduction-workflow.md` 执行。

### 已有图片复现

包括 image2 生成图、截图、论文图、架构图、流程图、SVG/PNG/PDF 参考图。

路线：

1. 先确认视觉目标和编辑目标。
2. 拆出主面板、文字、图标、箭头、表格、图例和不确定 OCR 内容。
3. 选择交付等级：视觉稳定版、固定背景可打开版、半可编辑版或全原生可编辑版。
4. 结构图优先使用 draw.io + 真实图标库 + Inkscape；真实数据图回到 Python 绘图；生物医学图标回到 BioRender。
5. 在目标软件中真实打开，并按全图裁剪证据放行。
6. 若任一局部出现溢出、重叠或错位，必须执行缺陷类型泛化协议。

### 图形摘要

用于摘要页、论文首页、综述主图。

路线：

1. 只表达一个中心 claim。
2. 使用 3 层以内结构：背景/问题 -> 方法/机制 -> 结果/意义。
3. 控制标签数量，避免把整篇论文塞进一张图。
4. 结论箭头必须与论文 claim 一致。

### 期刊封面和传播图

路线：

1. 允许使用 cinematic、3D、抽象光影和更强视觉隐喻。
2. 不放具体数据、P 值或实验结果。
3. 不要求每个实体都精确标注，但科学主题不能误导。

### 海报/幻灯片图

路线：

1. 一个图只传达一个信息。
2. 海报图最多 3-4 个元素，10-15 个词，50% 以上留白。
3. 幻灯片图优先大视觉、小文字、强对比。
4. 结果页优先复用已有数据图，不用 AI 重画数值图。
